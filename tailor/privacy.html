Privacy Policy — Jarvis backup

Last updated: 2026-10-19

Jarvis backup is a personal, single-user tool. It is used only by its owner and is not offered to anyone else.

  • Access: it requests only the drive.file scope, so it can see only the files it created itself in the owner's Google Drive.
  • Data: files are encrypted on the owner's computer before upload. No data is collected, sold or shared with third parties.
  • Storage: backups stay in the owner's own Google Drive account.
  • Contact: via the GitHub profile of this site's owner.
